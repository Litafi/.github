# Introduction 

The contents of this repo are used in various ways by GitHub. Here's a summary:
<br>
- `.github/ISSUE_TEMPLATE` are used by all organization repos directly. Changes to these templates will be available to every repo in the organization. 
  - _note:_ If repos have their own `.github/ISSUE_TEMPLATE` directory, these templates will not be available (so don't do that).
<br>

- `.github/workflows/` contains GitHub Actions with configuration that is used by all organization repos.
<br>

- `docs/` contains templates for CODE_OF_CONDUCT.md, etc.
<br>

- `etc/` contains global configuration, such as labels. 
<br>

- `profile/README.md` is our organizational README at 
<br>

- `workflow-templates` are templates available for manual selective incorporation into other repos.
<br>
